# Three.js animated cube with different textures

**Cube rotates and reacts on hover of buttons**

Live website: https://3-cube-shtyka.netlify.app/ \
Inspired by: https://corentinbernadou.com/

---

### Install

```bash
npm i
```

<br/>

### Run local server

```bash
npm run dev
```

<br />

---

### ✅ Done:

1. Textures appear in random position on each reload.
2. Cube rotates along `x` and `y` axes.
3. On button hover (and focus) - cube `scales`, `rotation` slows down and appropriate textures smoothly change `opacity`.
4. On button remove hover (and blur) - cube ges back to original `rotation` speed, `scale` and textures become solid.
5. Cube `rotates` with the same `speed` in all browsers and devices.
